## How to Preview & Run

This website is built with clean semantic HTML5, modern CSS3, and vanilla ES6 JavaScript. It has zero heavy dependencies and can be viewed immediately in any web browser.

### Option 1: Direct File Opening
Double-click `index.html` to open in any browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (Node.js)
```bash
npx serve .
# or
npx http-server -p 8080
```

## Deployment Options
* **GitHub Pages:** Push this repository to GitHub and enable GitHub Pages in repository settings.
* **Netlify / Vercel:** Drag and drop this folder or connect git repository for instant global CDN deployment.
* **cPanel / Apache / Nginx:** Upload files to `public_html`.
